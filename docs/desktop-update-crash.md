## 本轮修复

此前更新脚本只判断目标版本、指纹和服务是否就绪，没有校验原进程是否仍在。
现在更新前记下 Desktop 及其宿主的 PID、父 PID、启动时间和可执行文件，
安装后、等待就绪期间及探测成功后继续核验。原进程退出或被替换就失败，
不会等待另一个新进程再宣布热更新成功，也不主动请求重启。

失败写入权限为 `0600` 的 `result.json`；进程变更记录
`DESKTOP_PROCESS_CHANGED` 和核对前后的进程身份。原来的显式 `--restart` 和
未启动应用的正常打开路径不要求旧进程存活。没有给宿主提高堆上限或截断历史。

## 检查与交付范围

定向检查覆盖原进程不变的正常热加载、就绪失败、宿主或桌面退出后被替换、PID 复用、
服务探测期间退出、安装后请求热加载前退出，以及显式重启路径。
没有运行全量测试、浏览器、模拟器、真实 DSH 热重载或端到端场景，
也没有再次安装插件、终止正式进程或重发正式消息。

真实行为的后续检查应是在隔离 DSH 中恢复长会话并执行插件热重载，
同时记录宿主堆使用及分配/保留来源，核对会话与输入连续性。
该场景需主人在当前消息中明确要求后才运行。
