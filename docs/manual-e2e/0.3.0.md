# 0.3.0 发布前验收

2026 年 11 月 28 日，候选代码 `4f6ad73`，PR #19。Web 使用 Desktop 同版 CLI `0.2.2-rc.5`、隔离的 DSH Web 和 ego-browser。已核对加载的 `0.3.0` 插件包与候选包指纹一致。iOS 使用 iPhone Air 模拟器、iOS 27.0、App `0.3.0 (174)` 和 Maestro `2.10.0`。

| 场景 | 实测 | 结果 |
| --- | --- | --- |
| Web 搜索、项目筛选、打开结果、返回看板 | 101 条命中，首批 100 条不含目标。选择目标项目后出现唯一结果。为测试事项分配智能体后，从结果打开了右侧会话。取消搜索后恢复看板列表。 | 通过 |
| Web 在 Antigravity `session/resume` 挂起时停止 | 用 ACP 测试进程挂起恢复。点停止后该进程退出，界面显示「已停止」，被取消的输入未到达 `session/prompt`。 | 通过 |
| Web 从停止后的队列续聊 | 停止保留了已排队输入。再发一条新消息后，保留的输入在同一原生会话提交一次，界面清空队列。 | 通过 |
| Web 正常完成后自动出队 | 让当前轮正常完成，排队消息自动进入同一原生会话一次。 | 通过 |
| iOS 搜索、筛选、打开和返回 | DEBUG fixture 配合 Maestro。按项目筛到唯一结果并打开会话，返回后搜索词和筛选保留，取消后恢复看板。 | 通过 |
| iOS 持续断线 | DEBUG fixture 配合 Maestro。启动时无提示，打开测试会话触发持续断线，返回看板后出现「电脑未连接」。模拟器上的定向单测确认首次失败的宽限期跨自动重试延续，恢复后清除提示。 | 通过 |
| iOS 图片加载和预览 | DEBUG fixture 配合 Maestro。打开含图片的会话后直接打开全屏预览，期间没有发送新消息。 | 通过 |
| 正式 Antigravity CLI 与 iOS 已配对链路 | Web 停止、排队使用 ACP 测试进程。iOS 使用离线传输 fixture，真实配对后的断线恢复、图片读取待在已配对环境验收。 | 待补验 |

Web 侧 `0.2.2-rc.5` 正常结束会继续处理队列。点停止时，DSH 的 `sessionController.cancel` 使用 `keepInbox: true`，保留队列并结束当前驱动。停下之后下一次发送会启动新一轮。这两条路径分别验收。

自动检查方面，PR 前四项的定向回归、旧版 iPhone API 契约、lint、类型检查、三端构建通过。本轮复跑通用驱动单测 16 项、iOS 重连单测 1 项，以及 lint、类型检查和 iOS 模拟器构建，均通过。全量自动单测及自动 E2E 未运行，验收时 PR #19 的候选提交没有 GitHub 检查记录。

本机证据位于 `.local/manual-e2e/0.3.0-4f6ad73/`，包括 Web 搜索结果和会话截图、ACP 消息计数、Maestro 断线与图片截图，以及构建和定向单测日志。
