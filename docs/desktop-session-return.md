# Desktop 会话放大与返回

主人于 2026-11-18 确认：这一版不在嘟嘟面板内接入 DSH 侧栏。点击原有放大按钮仍打开 DSH 原生会话，在原生会话右上角的工具组中增加缩小按钮；按 Esc 或点击缩小按钮返回来源。

- 缩小按钮注册在公开的 `conversation.session.header.utilities` 列表席位，位于原生更多操作之前。使用 DSH 自己的紧凑 Button、Tooltip 和同一组的 28px 触摸区域、15px 图标；主人随后指定双箭头版本，使用 Lucide `Minimize2`。文字复用已审的「返回看板」，没有新增 App 文案。
- 从嘟嘟点击放大，或点击文件、图片等内容经原有 `sidebarRight.openResource` / `openTab` 进入原生会话时，均记录同一返回地址。两种入口共用 `selectSession`，避免自动预览遗漏缩小按钮。普通 DSH 会话不显示缩小按钮；切换到其他会话或主面板会取消这次返回地址。返回通过 `layout.selectPanel('dudu')` 完成，不调用会重置路由的主页动作，不替换 DSH 的原生主会话或右侧栏。
- 原来的看板范围、搜索、选中的会话（含列表之外的子事项）、列表分隔宽度和会话弹窗选择保留在本次放大的内存快照里。不同小组件按其布局 ID 区分。返回后消费这份快照；普通后续访问仍使用原有初始化规则。草稿和会话内容继续由 DSH 自己持有。
- Esc 在捕获阶段处理，避免被 DSH 的双击 Esc 停止生成逻辑计入。菜单、弹窗、团队面板、输入建议、输入法组合状态和终端保留自己的 Esc；关闭这些界面后再按 Esc 返回。

实现为 `ui/lib/session-expansion.js` 的返回地址、`session-return.jsx` 的页面状态快照，以及 `client.js` 的原生工具组注册。不需要全局替换主会话组件、挪动原生侧栏组件或修改 DSH 源码。

验证范围：针对性单元测试验证返回目标、一次性状态恢复、离开会话后的失效，以及 Esc 与原生停止操作的隔离；原生预览桥的定向检查覆盖资源与页面两类入口携带返回标记，并保留等待原生挂载和切换取消的规则；客户端构建契约、lint、typecheck。上一版已通过正式更新脚本热更新，回执为 `.local/desktop-updates/run-lYFlxg/result.json`。本次补齐预览入口和更换图标尚未安装，未运行真实 DSH、浏览器或 Desktop 界面验证。界面验证应在获得主人当条消息授权后，用隔离 DSH 检查：放大及文件、图片、变更预览 → 输入草稿 → Esc / 缩小按钮 → 原会话；菜单先关闭；生成中的 Esc 返回不停止生成；普通会话没有额外按钮。
