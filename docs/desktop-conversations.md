## 数据与认证

手机和 Desktop 使用同一个 `createChatHome` 实例和 `assistant/chat-home.db`。
普通 issue 结果的可选只读 `pinned` 也读这份记录；不写入事项元数据或工作流，不使用 DSH 自身侧栏的置顶。
会话摘要、排序时间和未读继续读取共享 activity projection；工作中保持上一次完整回复的时间和位置，
本轮完成后一起发布。列出、过滤、置顶和恢复引用不会确认已读；实际可见会话仍使用已有阅读回执。

Desktop 只新增 DSH 已认证连接上的 POST `/api/dudu/home/list` 和 `/api/dudu/home/pin`，
没有匿名页面、转发代理或新的传输方式。手机仍使用既有配对 API。原本由手机服务单独创建的 home
提前到共享服务初始化，并在手机服务结束后关闭；注册失败释放本次资源。
列表轮询在会话布局中停用，会话轮询在其他布局中停用，不同时读取两套页面数据。
