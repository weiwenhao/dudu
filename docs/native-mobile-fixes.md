## 新建事项页高度和按钮一排（2026-11-17，接上一条）

主人装上 build 127 后截了一张图：页面几乎满屏，下面一大片空白；状态、优先级……那一排按钮被一个转圈替掉。
主人问“按钮不就是按钮吗？写死就行了，你从哪里 loading 的”。

按钮：原来要等电脑回答 `issue.options`（状态、标签、项目）才画这一排，没回来就转圈。现在这一排永远在：
状态、项目、标签三个要用电脑给的内容的按钮在回答到之前点不动，优先级和“更多”一直能用；状态按钮先写“状态”，回答来了再换成默认状态的名字；
只有真的加载失败才在这一排下面写“事项没能加载”和“重试”，没有新增文字。

高度：页面高度 = 表单高度 + 顶栏高度，顶栏高度原来是“表单在页面里的位置 + 顶栏的安全区”。这个位置是从屏幕顶量的，页面一升高它就变大，
高度档位跟着变大，页面再升高……直到满屏（量到的数：表单 261，应加的顶栏 74，实际加了 216，档位 477，页面却 844）。现在只加顶栏的安全区，再加主屏幕底部横条的高度
（`DSBotLayout.windowSafeAreaBottom`，键盘出来时它不变）。高度档位变了，页面认的是另一个档位，所以档位的选择跟着表单走（和智能体团队页同一做法），
这也是加照片、出现失败提示这些改变表单高度的情况需要的。相册选择器放在表单上，不再和页面的高度修饰并排。

检查：模拟器 Debug（含界面测试）看了键盘在、键盘不在、3 张图、9 张图、选项没到五种状态，页面都刚好包住表单，最下面一排按钮在底部横条上面；

## 会话白屏：估算高度过高，视口落在没有行的地方（2026-11-07）

主人 12:37 的截图：从看板打开一个正在跑的会话，正文全白，向前滑了一段才出现内容。当时从实体 iPhone
（build 36）读取诊断，记录在 `.local/device-logs/2026-11-07T04-38-51.702Z/`：

- 12:37:41 打开一个 20 项的历史，第一次布局：SwiftUI 估算的内容高度 14,982，视口在估算的底部
  （偏移 14,070）；整个列表只建出 1 行（一条 1,652 点高的长回复，比 912 的视口还高），它的底边在视口
  顶上 252 点；最后一项（136 点）没有建出。视口里没有任何行，所以是白的。
- 之后 5 秒没有新的布局；两次“定位到最新”都定在同一个偏移上，没有移动。开始滑动后，每次手松，
  “跟随最新”又把视口放回估算的底部（偏移 15,567、15,612；估算此时已涨到 16,434）。
- 真实内容只有 13,955，估算高了 2,479。滑到偏移约 13,203 时真正的行才建出来，估算校正，白屏消失。

这不是 build 36 才有的：三天的诊断里“视口没有行”出现在 25 个以上的历史上，绝大多数在一秒内自己恢复；
用户碰到屏幕时仍是空白的只有两次：11-06 17:32（build 35：新消息先把视口放到估算的底部，0.8 秒后
自己恢复）和今天这次。所以从看板打开会话这条新路径不是原因。

原因（由日志判断，没有复现）：懒加载列表在建出末尾的行之前只有估算高度，估算可以比真实高得多；
“跟随最新”去的是估算的底部，估算偏高时视口就越过最后一行，那里没有东西可画，也没有行被建出来去校正
估算；再去同一个位置不会移动，所以停在白屏上。

修改：`BlankViewportRecovery`（`ChatScrollPosition.swift`，纯函数）和 `ScrollMetrics.recoveryTarget`。
跟随最新时，如果最新一行没有建出、视口里又没有任何已建出的行，就去最后一个已建出的行
（`proxy.scrollTo(该行, anchor: .bottom)`，它的位置是真实的）；同一个估算（内容高度没变）不再被信任，
每次都去那一行，所以滑动结束后不会再被放回估算的底部；行建出后估算变了，就恢复原来的做法。消息到来时
视口里还有已建出的行，照原样跟随。没有加定时、重试、UIKit 偏移写入或高度缓存。触发时在诊断里记一条
`chat.scroll.command`，状态是 `<原因>.recover`。

验证：把同一个纯函数用 `swiftc` 单独编译，跑了 9 个情形（日志里的那一次、再次请求、估算校正后、新估算、
消息到来、没有任何行、与行的顺序无关、原有两个判断不变），全部通过；同样的用例已写进
`ChatScrollPositionTests.swift`，但 Xcode 的模拟器单元测试没有跑完（首次为模拟器编译依赖要十多分钟，
主人要求立刻安装手机，中止了）。`npm run native:build` 通过，已安装为 Dudu 0.3.0 (37)，设备查询确认。

没有验证：**没有在模拟器里复现过白屏**。手机是 iOS 27.0.1，现有模拟器是 26.3.1 和 18.6，这一类问题此前在
