# dsbot 电脑连接插件

dsbot `0.3.8` 为 SwiftUI iPhone 客户端提供原生会话连接和带鉴权的 HTTP 页面。
发布包 `dsbot-desktop-0.3.8.zip` 包含 `dsbot-0.3.8.tgz`。
当前与 DeepSeek Harness Desktop `0.2.1-rc.2` 联调。

## 安装与配对

1. 在 DSH Desktop「插件」中安装 `dsbot-0.3.8.tgz`。
2. 打开 DSH Desktop「设置 → 手机控制」，填写电脑名称。
3. 添加一个或多个手机可访问的连接地址。
4. 在目标地址旁手动点击「生成二维码」。
5. 手机打开 dsbot，扫码或粘贴完整配对链接；已连接时可在「电脑连接 → 添加电脑」继续配对。

地址不区分局域网与公网模式。配置 TLS 的反向代理或隧道可填写
`https://your-domain.example/dsbot`，局域网可填写 `http://电脑地址:3170/dsbot`。
WebView 按用户填写的 HTTP/HTTPS 协议直接加载手机适配页面。
页面固定保留根据当前内网 IP 自动生成的地址，不能修改或删除；
网络变化后自动更新，其他地址仍可自行管理。
添加地址、保存配置或打开页面均不会自动生成配对码。

首次配对码有效 10 分钟。配对成功后保留连接凭据；在电脑端撤销某台手机会断开
其连接，并阻止它再次认证。手机可保存、切换多台电脑。同一台电脑的地址变化后
重新扫码会更新已有记录。

## 手机可使用的会话功能

`0.3.3` 起，已认证的手机可以对当前会话执行白名单命令 `/goal`、`/plan`、`/compact`，
把照片和文件作为附件随消息发送，并获得结构化的对话记录（思考、工具调用、用时和用量）。
白名单之外的命令一律拒绝；文件只通过 DSH 自带的上传接口暂存，单个文件不超过 16 MB。
`0.3.4` 起，手机还可以读取模型的推理等级和可用的 Agent 预设（模式），在新会话中选择项目和模式，
并修改当前会话的推理等级；预设只能取自 DSH 返回的列表。
`0.3.5` 起，手机从插件读取 DSH 的侧栏入口、会话视图、右侧面板入口和设置分区（含图标），
其他插件新增的内容会自动出现在手机上；DSH 窗口把这些内容报告给插件，插件保存最近一份
（`DSH_HOME/dsbot/navigation.json`）。升级插件后请打开一次 DSH 窗口，手机才会拿到完整列表。
`0.3.6` 起，会话列表带上 DSH 的归档、置顶和每个工作区里的顺序，并支持重命名工作区、删除工作区的登记
和取消归档；设置里不再列出「通用设置」。
`0.3.7` 起，右侧面板的「新建终端」和「浏览器」会列给手机。终端是电脑上的真实 shell（电脑用户身份，
工作目录是会话的工作区），页面传输新增 `web.stream.send` 承载键盘输入：只有右侧面板页面可用，
只限页面所属的会话，只接受 `terminal/attach` 的 `write` 和 `resize`，并校验大小和序号；
输出按批下行。浏览器只在右侧面板页面的 CSP 里放开 `frame-src http: https:`，其他页面仍是 `'none'`。
`0.3.8` 起，会话详情带上 DSH 的任务清单（`todos`，只读：内容和状态）；手机可以置顶、取消置顶和归档会话（`session.pin`、`session.archive`，对应 DSH 的 `workspace/pinSession`、
`unpinSession`、`archiveSession`，不带「停止运行中的工作」选项：有任务在跑时 DSH 会拒绝，要在电脑上确认）；
DSH 没有删除会话的接口，插件也不提供；用到遮罩、裁剪、渐变等 SVG 特性的侧栏图标，
DSH 窗口会把它渲染成 64×64 的小图再传输，插件校验 PNG 文件头和尺寸，单个不超过 16 KB。
旧版 App 或旧版插件缺少这些方法时会自动退回到原有的纯文本对话。

## 公网入口

将 `/dsbot` 及其子路径转发到安装插件的电脑 `3170` 端口。
原生会话使用 `/dsbot/api/v1/` 下的鉴权 HTTP API 和事件长轮询；复杂页面使用
`/dsbot/web/open` 和 `/dsbot/ui/` 下的 HTTP 请求。无需转发 DSH 网页、
`/api/` 或其他路径。未鉴权的页面、资源及操作不会被提供。

HTTPS 使用系统证书验证。原生 API 和网页会话的打开请求均通过 Authorization
请求头携带配对凭据。请求 URL 和网页脚本
均不携带配对密钥。网页文档、资源和操作使用独立且仅适用于该页面的
HttpOnly Cookie。认证后仅允许限定的业务方法，不提供任意 HTTP 或 DSH RPC 代理。
反向代理会终止 TLS，中转服务器可以接触解密后的流量。

App 与插件只通过 HTTP/HTTPS 通信，不使用 WebSocket Upgrade。旧版配对链接中的
WS/WSS scheme 只会在 App 导入时归一化为 HTTP/HTTPS；新地址请填写 HTTP 或 HTTPS。

插件会验证配置地址是否到达这台电脑，再签发配对码。安装包不包含个人域名、
证书、托管中继或预置电脑地址。与其他服务共用一个域名时，
为 `/dsbot` 及其子路径设置独立路由即可，其他服务保持自己的路由。

## 维护与升级

电脑需要保持 DSH 和连接隧道运行。配置和设备记录保存在
`DSH_HOME/dsbot/`，默认 `~/.dsh/dsbot/`。重启或升级保留已有记录，
设备密钥以散列形式保存。

从旧版升级时，手机使用原 bundle identifier 覆盖安装，保留 Keychain 和数据。
旧凭据只在实际认证时按迁移规则导入；撤销后的旧凭据不能再次导入。
旧的网页中继不再通过公网转发，也不打包进此插件。

此包仅包含电脑插件。手机 App 需通过适用的 Apple 签名、TestFlight 或
App Store 分发。Windows 和 Linux 的电脑端安装尚未实机验证。
